# Project 11 — Galeri Data Gambar & Detail View (React.js)

Project mandiri untuk Soal No. 11:
- Menu utama menampilkan List Data Image (grid kartu gambar dengan judul, subjudul, pencarian, dan tombol favorit).
- Ketika salah satu gambar diketuk, aplikasi menampilkan halaman detail gambar lengkap dengan tombol Putar/Jeda audio pratinjau, tombol bisukan suara, dan metadata katalog.

## Menjalankan secara terpisah
```bash
cd project-11-image-gallery
npm install
npm run dev
```
